# 檔案收錄說明

本目錄以使用者指定的六個控制入口為主線，加入其依賴的 source、設定、地圖、車體模型，以及車輛辨識、禁停區與相機模組。檔案以複製方式收錄，原資料夾保留。這是待確認版本的整理目錄，不表示所有候選程式都在實車同時執行。

## 收錄範圍

| 類別 | 收錄內容與理由 |
|---|---|
| Mega 與尺寸圖 | 新增使用者指定 sketch 及底部尺寸原圖，分別放在 firmware/ 與 docs/images/；未改動韌體。 |
| 主控制 | `ros2_ws/odem_bridge.py`、myagv.sh、lidar.sh、local.sh、nav1.sh、map.sh；保留對應 URDF、Nav2 YAML、地圖及輔助 GUI。 |
| 定位與地圖工具 | `lidar_localization_ros2`、`ndt_omp_ros2`；另留 `pcd2pgm-main` 作選用地圖轉換工具。 |
| 光達 | `ros2_ws/src/ouster-ros` 與 `ous/src/ouster-ros` 兩個候選版本，含各自 SDK、LICENSE、建置來源。兩套不能在同一環境混合使用。 |
| 感知與巡檢 | ROS 辨識與禁停判定套件、本地修改版 OpenPCDet、權重、zones.yaml、相機上傳程式。 |
| 部署參考 | `reference/deployed_localization` 保留原 install 中的定位 launch 與參數；`reference/upstream_patches` 保留可取得的上游本地修改差異；`reference/navigation_investigation` 保存根目錄入口／URDF、地圖旁支與無時間背景的 TF 快照，供室外調查比對，不視為主啟動流程。 |
| 報告 | 既有 `專題技術報告.md`、本次整理的控制報告與架構文件，以及控制章節更新版 PDF。PDF 未修改的其他章節仍可能有舊描述。 |
| 實車辨識參數 | config/vehicle_detector.yaml 依使用者提供內容新建，四項門檻皆為 0.4；需明確載入。原廠硬體資料以連結與查核摘要記錄，未把手冊原檔納入再散布。 |
| 開源準備 | README、安裝／設定／驗證文件、缺漏清單、依賴分組、LFS 規則、授權狀態、貢獻範本、靜態檢查工具。 |

第三方套件保留其 source tree 的建置檔、標頭、CUDA source、LICENSE 與原有文件／測試，避免只抄執行檔導致無法重建；這不表示已詳細審閱每一個第三方檔案。沒有收錄與主線無關的完整備份、OpenPCDet 訓練資料集，以及另一套未確認使用的根目錄 motor_bridge.py。

## 排除內容

不收錄巢狀 `.git`、`build/`、`install/`、`log/`、虛擬環境、快取、編輯器暫存及舊 `.so`／`.a`／`.o`。生成的 ROS setup 應由目標環境重新建置；舊 Python 3.8 ARM64 擴充不能視為通用安裝套件。原 install 中需要核對的設定以普通參考檔另存，並未把整個 install 目錄搬入。

## 複本差異與來源紀錄

- 程式複本只有相機上傳的固定 GAS 部署網址改為讀取 `AMR_GAS_URL`，日誌改為顯示是否已設定；原始程式沒有改動。
- 架構文件的部署參考連結改指向本目錄的快照；架構、控制報告與缺漏文件已納入使用者補充的韌體、幾何與實車資訊。PDF 保留前次版本，以 Markdown 為最新內容。
- 其他收錄的 source 與資源保持複製當時內容；已知語法錯誤或缺漏記錄於清單，未擅自推定原部署並修補。
- [copied_files_manifest.json](copied_files_manifest.json) 記錄 2,694 個複製檔案（原 2,684 個，加上 Mega sketch、尺寸原圖、室外調查的 5 個旁支快照及 IMU 查核的 3 個旁支檔案）的來源相對路徑、目的地、來源與複本 SHA-256。工作區來源相對路徑以原 `ntust/` 為基準，目的地以本 `github/` 為基準；使用者圖片附件以 source_kind=user_attachment 及原檔名記錄。
- [upstream_versions.json](upstream_versions.json) 記錄可取得的上游 branch、commit 與本地變更。存在本地修改時，該 commit 只是來源線索，不能當成完全相同的實車版本。
- 本次新增文件及工具不在複製清單內；整體驗證摘要見 [整理與檢查結果](整理與檢查結果.md)。

第三方來源已平鋪複製到此目錄，不依賴原備份內的 Git metadata。保留的第三方 `.gitmodules` 屬來源紀錄；本專案並未建立可直接 `git submodule update` 還原的頂層 submodule 配置。
