# 檔案缺漏與待確認事項

最新更新：2026-09-24，已納入拆車現況、實車調校背景、近似效能回報、IMU 查核，以及已確認有室內／室外地圖與室外無法移動的調查。既有硬體、座標、辨識參數與原廠查核結果一併保留。疑問集中記錄；不推定缺檔一定由 Google Drive 下載造成。

## 拆車後的整理原則

車輛已拆除，許多實際量測與接線資訊無法補全。使用者說明大部分程式參數曾按實車狀況調整，故保留原部署值，不僅因與標稱尺寸不同就認定錯誤。個別校正過程、倍率及靜態幾何差異仍如實註記，不宣稱全部已驗證。無法補測的項目列為歷史資料缺口，不再反覆要求補件，也不阻止完成報告與歷史程式整理。

## 室外故障調查新增紀錄

- **降為備選的 QoS 問題**：官方 Foxy navigation_launch 將 map_subscribe_transient_local 預設覆寫為 false；但 run.md 記錄導航先、地圖後，不支持直接假設晚加入。設定覆寫仍成立，故保留為重建／重啟時的查核項目，不再列首要歷史嫌疑。
- **Ouster 啟動檔缺口**：主腳本指定 sensor.launch.xml，但備份中未找到確切檔名；有 sensor.composite.launch.xml 等候選，可能為安裝檔／連結未備份或版本差異。當時曾有點雲回報，不能回推當時驅動必定失敗。
- **歷史證據缺口**：操作順序已由 run.md 補足；仍未找到故障當次各節點就緒／重啟時間及執行日誌、實際 Nav2 安裝 launch／版本、有效參數、TF／cmd_vel 錄製與 RViz 設定。建置日誌和第三方 sample bag 不替代實車紀錄。
- **其他設定差異**：定位 PCD 尾端覆寫、工作目錄影響 overlay／URDF、零初始位姿、光達 TF、footprint，以及 Foxy 單數 goal_checker_plugin 與現有複數設定差異，均已分級說明。原控制檔保留。

詳細證據、候選修正命令與查核順序見 [室外導航調查](室外導航無法移動_調查報告.md)。無法補測的項目維持歷史缺口，不要求重新組車。

## 已知程式問題與檢查方向

以下保留靜態分析結果，未修改控制或辨識程式。涉及硬體量測的檢查方向供未來重建參考，並非要求原車補測。

| 項目 | 狀態與影響 |
|---|---|
| Footprint 軸向 | 已確認 STL 原點為 O、車頭為 +x；現有 Nav2 外框長邊沿 y，與尺寸圖不一致。幾何參考值已寫入硬體文件，導航 YAML 本次未修改。 |
| 辨識 launch 語法 | 三段舊 Node 的宣告已註解，但其 parameters 字典內容與結尾仍留在程式中；第 72 行附近先被 AST 偵測。來源用途已釐清，語法問題仍存在。後續應整理筆電測試殘留。 |
| 兩個自製 console entry points | setup.py 仍宣告 map_server_node、localizer_node，但模組不存在。依本次說明可列為舊測試入口待清理，而非預設必須找回的實車主功能。 |
| KITTI 評估工具 | OpenPCDet 的 kitti_object_eval_python/evaluate.py 第 5 行 import .kitti_common as kitti 無效；屬 KITTI 評估，尚無證據表明主 nuScenes 推論必經此檔。 |
| Ouster SDK Python 入口 | 新版 SDK setup.py 指向 ouster.sdk.simple_viz，對應模組未找到。需核對 SDK 封裝版本；不等於 ROS C++ 驅動已證實失效。 |
| NDT 函式庫匯出 | ndt_omp_ros2 建立 ndt_omp，但安裝／匯出不完整的疑點待確認；下游有引用。未進行乾淨建置，不宣稱已實測編譯失敗。 |
| local-prefix 架構 | 定位環境腳本含 x86_64 路徑，需確認 Jetson ARM64 前綴。 |
| GPU 依賴 | NumPy 體素化備援不等於完全不需 spconv；版本組合與 OpenPCDet 來源 commit 尚待補。 |
| 序列與迴圈時序 | Mega parseFloat 可能阻塞主迴圈；Jetson 非阻塞 readline 未暫存半行。先測量丟行與延遲，不能僅靠提高 timer 頻率改善。 |
| 辨識時間戳 | sync_time_stamp=true 在 callback 開始重寫 stamp；辨識結果保留重寫時間。量測端到端延遲需另外保留原始感測時間，不以此參數宣稱已完成時鐘同步。 |
| 回授一致性與停止 | Mega 傳送 volatile long 時未取受保護的快照；500 ms 指令逾時分支存在，但阻塞、加減速及實車停止時間尚未驗證。 |

[靜態檢查結果](static_audit.json) 目前仍有 5 項原始錯誤（2 處語法、3 個不存在的入口模組），不因用途已釐清就改報成功。韌體的新分析是閱讀結果，不包含 Arduino 編譯測試。
