## 建議後續改善

- 以一個 ROS bringup package 統一啟動，避免多個 shell 腳本依賴工作目錄與舊帳號路徑。
- 自製套件補齊 package.xml runtime dependencies，取代僅存在於文件的手動依賴。
- 新增小型、可公開的 rosbag／點雲範例及無馬達模式，讓沒有實車的人也能重現感知結果。
- 確認硬體支持後加入有意義的 ROS integration tests，再把手動 CI 擴成 PR 檢查。
- 首次可重現版本提供 release notes、CHANGELOG、圖像或演示影片；不提前放「passing」或已選定授權的徽章。
- 若有學術引用需求再加入正確作者資訊的 CITATION.cff；如需多人協作，再設定 CODEOWNERS／行為準則與維護流程。

## 查核依據

GitHub 的 README 應讓讀者知道專案用途與如何開始；貢獻規範用獨立文件承接。[GitHub 專案溝通文件](https://docs.github.com/en/issues/tracking-your-work-with-issues/learning-about-issues/planning-and-tracking-work-for-your-team-or-project)

授權需有明確可讀的 LICENSE，不能只因 repository 公開就假定可自由使用。[GitHub 授權文件](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/adding-a-license-to-a-repository)

GitHub 一般 Git 不接受超過 100 MiB 的單檔；本案地圖實際超過限制，因此準備 Git LFS。[GitHub 大型檔案文件](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)

ROS workspace 的標準建置與 overlay 載入方式，參照 [colcon 官方教學](https://github.com/ros2/ros2_documentation/blob/humble/source/Tutorials/Beginner-Client-Libraries/Colcon-Tutorial.rst)；Jetson 的 PyTorch 則以 [NVIDIA 相容安裝指引](https://docs.nvidia.com/deeplearning/frameworks/install-pytorch-jetson-platform/index.html) 為準。本專案是否已支援某版本，仍以自己的建置／測試紀錄判定。
