## 靜態檢查結果

後續資訊更新已確認編碼器 1000 線、驅動器 1600 細分。文件補入 A 雙邊緣計數的條件式推算及 ppr=1600 待核對事項；此次另將使用者提供的辨識參數存為 config/vehicle_detector.yaml；未改動原控制／辨識程式預設、導航 YAML 或韌體，也未執行硬體測試。

檢查 612 個 Python、10 個 ROS package XML、1 個 URDF、8 個 console-script 入口、91 個 CMake 安裝程式路徑及 34 個 CUDA extension source 宣告。XML／URDF 解析及本次檢查涵蓋的 CMake／CUDA 檔案存在性檢查通過。

整體靜態檢查**未通過**，保留 5 項原始問題：辨識 launch 與 KITTI 評估工具各一處 Python 語法錯誤；兩個自製 ROS 入口及一個 SDK Python 入口找不到對應模組。詳見 [缺漏清單](檔案缺漏與待確認事項.md) 與 [機器可讀結果](static_audit.json)。沒有為取得成功狀態而隱藏這些問題。

使用者已確認 ROS 2 Foxy／Ubuntu 20.04，README 與安裝指引已改用該基線。主機已確認為 AGX Xavier，馬達型號已從原報告及原廠核對，14 mm 為輸出軸直徑；STL 原點為 O、圖右為 +x。現有 footprint 軸向不符已記錄，原廠配套驅動器手冊已找到但實車型號未確認。NDT 函式庫匯出、其他版本來源在 Foxy 的相容性、固定路徑和 TF／地圖一致性仍屬後續建置與部署核對事項，未被上述語法檢查證實通過或失敗。
